# CFU-Playground 学习计划（无 FPGA / Renode 路径）

> 目标：在没有 FPGA 板卡的前提下，用 Renode（+ Verilator 联仿 CFU）跑通整条链路，并亲手做出一个可测的自定义指令加速器。
>
> 环境：`/home/hjadmin/zw/infer-infrastructure/cfu-playground`（已部署）  
> 起点：**先读 Overview，再动手；别深挖某一层太久。**
>
> 节奏假设：每天约 **1.5–2 小时**，约 **4 周**。可按周末压缩/拉长。

---

## 怎么用这份计划

1. 每天开始前：勾选当天任务；做完在「笔记」栏写 3–5 句收获。
2. 命令默认在项目根或对应 `proj/xxx` 下执行。`make` 已可自动找本地 `cfu-common`；也可：
   ```bash
   source /home/hjadmin/zw/infer-infrastructure/cfu-playground/enter-env.sh
   ```
3. **无板卡替代**：文档里的 `make prog` / `make load` → 一律用：
   ```bash
   make renode-headless    # 交互仿真（UART 菜单）
   # 或
   make renode-test        # 自动化冒烟
   ```
4. Renode 无 GUI：默认进 UART；按 `` ` `` 切到 Monitor，`uart_connect sysbus.uart` 切回。

## 学习原则（官方建议浓缩）

1. **广度优先**：TFLM / RISC-V / 门级 / LiteX 都懂一点，再加深。
2. **先剖析再加速**：没有 cycle 数字就不要加硬件。
3. **先软件特化，再 CFU**：能用 C 证明算法简化，再搬到门级。
4. **正确性闸门**：golden / hw-sw compare 不过，不谈加速比。
5. **CFU 不直接碰内存**：CPU 负责搬数——设计时把「数据搬运」算进成本。
