# 心智模型（纠偏用）

先用这段改写学员的问题，再动手。

## 推理慢，通常不是「还没读 llama.cpp」

一次 decode 只吃 1 个新 token，却要做完 embedding、RMSNorm、QKV、RoPE、注意力、FFN。权重是一大块连续 float，激活可以每层复用同一块缓冲。

还没能指出「算的是什么、存在哪」时，SIMD、量化、CUDA、服务框架都没有验收对象。

三份材料各管一层：

| 材料 | 层 | 真正解决 | 不解决 |
|------|----|----------|--------|
| llama2.c | 计算 + 内存本质 | 无框架的前向、一维权重、激活复用 | 模块化框架、多后端 |
| 学员的 `engine/` | 同一套计算的 C++ 与测量 | RAII、Tensor 视图、对拍、AVX2、KV cache | 工业级图调度 |
| tiny-cnn | 框架设计 | 算子接口、模板分发、布局（NCHW/NHWC）、SIMD 写在哪 | Llama 生成 |
| llama.cpp 核心 | 工业引擎的骨架 | 张量 + 内存池 + 计算图、KV、量化块布局 | 把上面全部读完，或在线高 QPS |

## 把口头问题改写成工程问题

| 学员说 | 先改写成 | 你实际带他做 |
|--------|----------|----------------|
| 我要啃完 llama.cpp | 要看的是张量、分配器、图、KV、量化块 | 主干未完成就拒绝；完成了也只读锚点 |
| 我要写 CUDA / FlashAttention | 朴素 GEMV 的带宽数字有了吗 | 没有对拍的 C++ 前向 → 回到当前课 |
| 用 AVX2 把推理加速 | 哪一个算子、相对哪一版朴素实现 | S3：先基线，再 intrinsics，同时交误差 |
| tiny-cnn 是 CNN，跳过 | 要学的是算子怎么注册、热路径怎么避免虚调用 | M1，卷积只是样本 |
| 先做 4bit 量化再看前向 | 量化是权重的内存布局，前面必须有一份 fp32 对拍 | M2 的 L19，且不要求写完整量化 matmul |
| 读 vLLM / TensorRT 源码入门 | 你还缺一块「自己拥有的、可对拍的前向」 | 拉回 PLAN 当前课 |
| 三个仓库克隆完就算学完 | 要有 token 对拍和延迟表 | 对着 `learn/GOALS.md` 验收 |

改写格式（每轮开头）：

```
你问的是：…
真正的问题是：…
所以今天做：…（不做：…）
```

## 环境

- 编译器：`g++ --version`、`cmake --version`。C++17。
- AVX2：编译加 `-mavx2 -mfma`，运行前确认 `lscpu` 里有 `avx2`。没有 AVX2 就改用学员机器实际有的 ISA，并在 PROGRESS 写明，不要假装测了 AVX2。
- 不要为本课安装 CUDA、TensorRT、vLLM。
- 上游 llama2.c 的 `run.c` 里已经有 `key_cache`。学员的 L08 **先写无 cache 的整段重算**，用来和官方 `run` 对 token；L11 再自己加 cache。官方二进制只作为 token 参照，不作为「cache 已经学过了」的证明。

## 测量词（S3 起强制使用）

- **对拍**：同一 prompt、greedy（temperature 0）、token 序列一致；或逐元素 max abs diff
- **GEMV 延迟**：`M=1` 的矩阵向量乘，记下 rows、cols、毫秒、CPU
- **逐步延迟**：生成 16 token 的总时间；序列拉长后，有 cache 应低于无 cache 重算
- **字节**：一块量化相对同样元素数的 fp32 少多少字节

「变快了」必须带：对比对象、尺寸或 prompt 长度、硬件。
